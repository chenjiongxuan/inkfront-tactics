# 墨线守城 · Inkfront Tactics

一款手机和电脑都能直接打开的单机关卡游戏。战斗采用纵向双层画面：上方是实时攻防近景，下方是六乘六布阵棋盘和环形行军道路。保留暗色纸张、粗描边和手绘角色风格。

## 在线游玩

**[点击打开游戏](https://chenjiongxuan.github.io/inkfront-tactics/)**

GitHub Pages 从本仓库的 `main` 分支根目录发布。公开链接可直接游玩，无需下载或安装。首次打开需要联网；游戏没有外部美术或音频依赖。少量段位、金币和宝箱进度保存在当前浏览器。

## 玩法

1. 在主界面点击“开始守城”，消耗 5 点体力。棋盘上已有三位守卫。
2. 点击下方手牌，再点中央棋盘格放置。相同守卫叠放可以升级至 Lv.3。
3. “锋芒”和“鼓舞”强化相邻守卫；“路障”减速附近行军敌人。
4. 点击“开始第 1 波”。敌军沿棋盘外圈箭头移动，守卫自动攻击；敌人走完整圈会损伤城门。
5. 击败敌军得到肉块。花 20 肉块补充空手牌，花 10 肉块刷新现有手牌，每波最多刷新 3 次。
6. 守住三波获得金币和宝箱。战斗可切换 1 倍或 2 倍速度。

## 实现

`index.html` 包含全部游戏代码、画面和合成音效，没有构建步骤和第三方运行依赖。当前是一关三波的完整可玩版本；段位与宝箱为轻量进度系统。
