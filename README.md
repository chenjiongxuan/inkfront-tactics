# 墨线守城 · Inkfront Tactics

一款可在手机或电脑浏览器直接打开的原创手绘策略游戏。上方是实时攻城战场，下方蓝框内是 6×6 路线构筑棋盘。

## 在线游玩

**[点击打开游戏](https://chenjiongxuan.github.io/inkfront-tactics/)**

由 GitHub Pages 公开发布，无需下载或安装。全部游戏代码、画面与音效都在仓库根目录的 `index.html`。段位、金币和宝箱进度仅占当前浏览器少量存储。

## 核心玩法

1. 每局随机生成 **5 块石头**，石头不可移动。营帐内的士兵在普通格按到左下角固定出口的最短格数行军。开局石头不会完全堵死路线。
2. 每个 Buff 有随机朝向的 **1 个蓝色入口、1 个金色出口**，两口可以相邻或相对。只有从蓝口进入才能获得加成；随后必须从金口离开。出金口撞石头、从其他方向进入 Buff，士兵都会死亡。重复踩同一 Buff 不会重复加成；过长的循环也会导致阵亡。
3. Buff 的强制出口可把士兵带离原本的最短路，让士兵继续连接其他 Buff。攻击、生命、护甲和攻速有明确数值；倍率按实际经过时的现有属性结算，所以顺序影响结果。
4. 下方随机三选一。先选卡，再点棋盘空格预览路线、生死原因和预计属性；再次点同一格确认放置。已放置的 Buff 可以移动，同类型同等级可合成，保留目标格的入口和出口朝向。朝向不能旋转。
5. 士兵离开棋盘后搭乘外圈传送带，抵达上方战场自动攻城。营帐自动出兵；20 肉块立即招募，10 肉块重抽三张卡。每击败 8 名敌人或进入新波次获得构筑机会。
6. 一局有 **5 波，约 3 分 10 秒**，第五波出现终局首领。击败首领并攻破敌堡获胜；我方城门耗尽则失败。界面显示波次、剩余时间、预计出征属性、敌兵属性、双方城堡生命、伤害数字和棋盘阵亡人数。可暂停或切换 2 倍速度。

## 实现

无构建步骤或第三方运行依赖。玩法根据用户提供的设计与战斗截图实现；游戏美术与代码为本项目原创。
