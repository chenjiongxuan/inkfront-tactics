# 墨线守城 · Inkfront Tactics

一款可直接在手机或电脑浏览器打开的原创手绘游戏。战斗画面采用纵向双层布局：上方自动攻城，下方经营移动的士兵装备生产线。

## 在线游玩

**[点击打开游戏](https://chenjiongxuan.github.io/inkfront-tactics/)**

本页由 GitHub Pages 发布，无需下载或安装。首次打开需要联网；游戏没有外部美术或音频依赖。少量段位、金币和宝箱进度保存在当前浏览器。

## 玩法

1. 点击“开始守城”进入布置阶段。此时战斗暂停，可以先整理棋盘。
2. 青色外圈是**己方士兵生产线**。士兵自动从入口出发，沿生产线拾取附近装备，再从出口进入上方战场。
3. 商店装备花 25 肉块。点卡牌再点空格购买；点棋盘装备再点空格移动。把同种、同等级装备拖到一起，或依次点选，可合成更高等级。
4. 点击“启动生产线”开始实时战斗。士兵自动与敌军交锋并攻打右侧堡垒。
5. 花 20 肉块立即招募一名士兵。击败敌军获得肉块；花 10 肉块刷新商店，每波最多 3 次。
6. 击破敌军堡垒获胜；我方城门生命耗尽则失败。可暂停或切换 2 倍速度。

## 实现

`index.html` 包含全部代码、绘制画面与合成音效，无构建步骤或第三方运行依赖。玩法参考用户提供的画面，以及 [War Factory 的官方商店说明](https://play.google.com/store/apps/details?id=com.xp101.war.factory.horde.survival)中关于装备生产线、合成与自动作战的机制。游戏素材与代码均为本项目原创，并未复制原游戏资源。
