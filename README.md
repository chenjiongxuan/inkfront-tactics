# 墨线守城 · Inkfront Tactics

根据提供的“主界面”和“核心战斗”两份规划制作的单机游戏。画面以第三张参考图的暗色战场、纸张质感、粗线条和涂鸦角色为方向，所有角色和画面均为代码原创绘制。

## 在线游玩

**[点击打开游戏](https://chenjiongxuan.github.io/inkfront-tactics/)**

网页由 GitHub Pages 从本仓库的 `main` 分支根目录发布。直接打开链接即可玩，手机和电脑都可以使用，无需下载或安装。首次加载需要联网；游戏运行时没有外部资源请求。游戏进度存于当前浏览器的少量本地存储中。

## 玩法

1. 主界面点击“开始守城”，消耗 5 点体力。
2. 点击三名英雄卡牌，再点击地图上的深色空格，分别部署铁甲小熊、游侠小狐和星纹法师。
3. 点击“开始第 1 波”。敌人沿浅色道路前进，英雄自动攻击。
4. 击败敌人获得金币。战斗中可在非道路格放箭塔或路障。箭塔自动攻击；路障减缓附近敌人。
5. 守住三波获胜，获得金币和宝箱。主界面可开宝箱、查看段位。

## 操作与范围

- 鼠标和触屏都支持点击布阵；速度按钮可切换 1 倍和 2 倍。
- 本版本是一关三波的完整可玩切片，段位和宝箱为轻量级反馈系统。参考规划中未给出完整数值和后端规则的部分，采用独立设计的原型数值。
- `index.html` 包含全部游戏代码、美术和音效；不使用外部图片或依赖。
