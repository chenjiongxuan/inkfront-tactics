# 墨线守城 · Inkfront Tactics

一款可在手机或电脑浏览器直接打开的原创手绘策略游戏。上方是实时攻城战场，下方蓝框内是 6×6 路线构筑棋盘。

## 在线游玩

**[点击打开游戏](https://chenjiongxuan.github.io/inkfront-tactics/)**

由 GitHub Pages 公开发布，无需下载或安装。首次打开需要联网；游戏没有外部美术或音频依赖。段位、金币和宝箱进度仅占当前浏览器少量存储。

## 核心玩法

1. 点击“开始守城”。先在暂停状态整理棋盘，黄色虚线显示营帐到左下角出口的预计路线。
2. 士兵从**棋盘内部营帐**出生，逐格走向固定出口。只有真正踩到攻击、护甲、生命、攻速或倍率格，才获得对应加成。倍率按经过时的现有属性计算，顺序影响结果。
3. 路障和营帐占格，可改变路线以引导士兵踩到想要的增益。会完全封死营帐或在途士兵出口的放置和移动会被拒绝。点击已有设施再点空格可移动；同类型同等级设施可合成至更高等级。
4. 士兵从棋盘出口进入**外圈传送带**，传送带只负责运送，随后抵达上方战场自动攻城。
5. 下方随机出现三张构筑卡，每次只选一张放到棋盘，另外两张放弃。开局有一次选择；每击败 8 名敌人或进入新波次又获得一次。花 10 肉块可重抽本轮三张卡，每波最多 3 次。
6. 营帐自动出兵；花 20 肉块可立即招募一名。击败敌军获得肉块。击破敌方堡垒获胜，我方城门耗尽则失败。可暂停或切换 2 倍速度。

## 实现

全部源码、画面绘制和合成音效均在仓库根目录的 `index.html`，无构建步骤或第三方运行依赖。玩法根据用户提供的设计与战斗截图实现；游戏美术与代码为本项目原创。
